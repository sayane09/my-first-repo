# 勤怠管理アプリ（スプレッドシート版）設置手順

記録をGoogleスプレッドシートに保存する本格版です。どの店舗のiPadで打刻しても、同じ人の記録が1つにまとまります。

## 用意するもの

- お客様の仕事用Googleアカウント（スプレッドシートの持ち主になります）
- このフォルダの2つのファイル
  - `Code.gs`（サーバー側の処理）
  - `index.html`（画面）

## 設置のしかた（15分ほど）

1. お客様のGoogleアカウントで、Googleドライブに新しいスプレッドシートを作ります。名前は「勤怠管理」など。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消して、`Code.gs` の中身を貼り付けます。
4. 左の「ファイル」の **＋ → HTML** で、名前を **`index`** にして作り、`index.html` の中身をすべて貼り付けます（名前は `index` ちょうどにしてください）。
5. 保存（💾）してから、上の関数の選択で **`setup`** を選んで **実行** します。
   - 初回は「承認が必要です」と出るので、お客様のアカウントを選んで許可します。
   - 「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進みます（自分で作ったスクリプトなので問題ありません）。
   - スプレッドシートに「スタッフ」「打刻」「修正履歴」「設定」のシートができれば成功です。
6. 右上の **デプロイ → 新しいデプロイ** を開き、種類で **ウェブアプリ** を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押すと、ウェブアプリのURLが出ます。これが打刻ページのアドレスです。
7. 日乃屋カレーのiPadでそのURLを開き、Safariの共有ボタンから「ホーム画面に追加」します。
8. 「スタッフ」タブでスタッフさんを登録し、「打刻」タブ右上の「この端末の店舗」で「日乃屋カレー」を選びます。
9. 必要なら「設定」タブで店長の暗証番号を決めます。

## 知っておくこと

- **計算ルールは固定**です（15分単位、出勤は切り上げ、退勤は切り捨て、休憩は近い方の15分）。変えたいときは `Code.gs` と `index.html` の `DEFAULT_SETTINGS` を直します。
- **打刻の時刻はサーバーの時計**で記録されます。iPadの時計がずれていても影響しません。
- **複数店舗で働く人**は、店舗を「日乃屋カレー、ドーナツ」のように「、」区切りで登録すると、どちらのお店のiPadにも名前が出ます。どこで打刻したかは「打刻した店舗」として残ります。
- **スタッフを削除しても、打刻の記録はシートに残ります**（給与の記録を守るため）。
- **アクセスは「全員」**にしているので、iPadにGoogleのログインは要りません。そのかわり、URLを知っている人は打刻できるので、URLはお店の外に出さないでください。修正や設定は店長の暗証番号で守れます（番号はサーバー側で確認しています）。
- スプレッドシートを直接書き換えることもできますが、形が崩れると読み込めなくなるので、ふだんの修正はアプリの画面から行ってください。

## あとで画面や処理を直したとき

Apps Scriptでファイルを直したあと、**デプロイ → デプロイを管理 → ✏️（編集）→ バージョン：新しいバージョン → デプロイ** を押します。こうするとURLが変わらず、iPadのホーム画面のアイコンもそのまま使えます。（「新しいデプロイ」を作るとURLが変わるので注意してください。）
